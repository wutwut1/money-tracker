# บัญชีรายรับรายจ่ายส่วนตัว

เว็บแอปบันทึกรายรับรายจ่ายสำหรับใช้คนเดียว เขียนด้วย HTML/CSS/JavaScript ล้วน ไม่ต้องติดตั้ง ไม่ต้อง build ไม่มี server และไม่ต้องสมัครสมาชิก ข้อมูลเก็บไว้ในเบราว์เซอร์ (localStorage)

## ฟีเจอร์
- เพิ่ม แก้ไข และลบรายการ โดยกรอกประเภท (รายรับ/รายจ่าย) จำนวนเงิน (ทศนิยมได้ไม่เกิน 2 ตำแหน่ง) หมวด วันที่ (ใส่วันนี้ไว้ให้ก่อน) และโน้ต ก่อนลบต้องกดยืนยัน
- ดูรายการทีละเดือน เรียงจากใหม่ไปเก่า รายรับเป็นสีเขียว (+) รายจ่ายเป็นสีแดง (-) กดปุ่ม ‹ › เพื่อเปลี่ยนเดือน ชื่อเดือนเป็นภาษาไทยและปี พ.ศ.
- การ์ดสรุปรายรับรวม รายจ่ายรวม และคงเหลือของเดือนที่เลือก
- กราฟวงกลมรายจ่ายแยกตามหมวด (บอกยอดและ %) และกราฟแท่งรายรับเทียบรายจ่ายย้อนหลัง 6 เดือน
- ตั้งงบรายเดือนของแต่ละหมวดรายจ่าย (ใช้งบเดียวกันทุกเดือน) แถบจะเป็นสีเขียวถ้าใช้ไม่ถึง 80% สีส้มถ้าใช้ 80–100% และสีแดงพร้อมข้อความ "เกินงบ ฿X" ถ้าเกิน 100% ถ้าบันทึกรายการแล้วเกินงบจะมีแจ้งเตือนขึ้นทันที
- จัดการหมวด: มีหมวดตั้งต้นให้ เพิ่มหมวด เปลี่ยนชื่อ และลบหมวดได้ แต่หมวดที่ยังมีรายการอยู่จะลบไม่ได้
- Export JSON (ไฟล์สำรอง), Import JSON และ Export CSV อยู่ในแท็บ "ตั้งค่า"
- ใช้บนจอมือถือกว้าง 360px ได้ และใช้บนคอมได้

## เปิดใช้บนคอม
ดับเบิลคลิกไฟล์ `index.html` ในโฟลเดอร์นี้ แล้วแอปจะเปิดใน Chrome หรือ Edge โดยไม่ต้องต่อเน็ต

ข้อควรรู้: ข้อมูลแยกกันตามเบราว์เซอร์และตามที่อยู่ของเว็บ ถ้าเปิดด้วยเบราว์เซอร์อื่น (เช่น เคยใช้ Chrome แล้วเปิดด้วย Edge) หรือเปิดจากเว็บที่ขึ้นโฮสต์แทนไฟล์ในเครื่อง แอปจะเริ่มจากข้อมูลว่าง ถ้าจะเปลี่ยนวิธีเปิด ให้ Export JSON ไว้ก่อนแล้วค่อย Import ในที่ใหม่

## ใช้บนมือถือ
มือถือเปิดไฟล์ `index.html` ตรงๆ ไม่สะดวก จึงต้องเอาแอปขึ้นเว็บ static เช่น GitHub Pages ก่อน (**ขั้นนี้ยังไม่ได้ทำ**) ซึ่งมีขั้นตอนคร่าวๆ ดังนี้
1. สมัครบัญชี GitHub แล้วสร้าง repository ใหม่
2. อัปโหลดไฟล์ `index.html` และโฟลเดอร์ `css/` กับ `js/` ขึ้นไป (`tests/`, `SPEC.md`, `PLAN.md` จะอัปขึ้นไปด้วยหรือไม่ก็ได้)
3. ไปที่ Settings > Pages แล้วเลือก branch ที่จะเผยแพร่ (เช่น `main` / root)
4. รอสักครู่ แล้วจะได้ลิงก์ประมาณ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` ให้เปิดลิงก์นี้บนมือถือ

หมายเหตุ: ถ้าเป็น repo สาธารณะ คนที่มีลิงก์จะเปิดตัวแอปได้ แต่จะไม่เห็นข้อมูลของคุณ เพราะข้อมูลเก็บอยู่ในเบราว์เซอร์ของแต่ละเครื่อง

**iPhone/iPad (Safari):** เปิดลิงก์แล้วกดปุ่มแชร์ จากนั้นเลือก "เพิ่มลงหน้าจอโฮม" (Add to Home Screen) จะเปิดใช้ได้ง่ายขึ้น และน่าจะช่วยลดโอกาสที่ Safari จะลบข้อมูลเมื่อไม่ได้เปิดนาน แต่ยังไม่ได้ทดสอบบนเครื่องจริง และแอปนี้ยังไม่ได้ทำเป็น PWA จึงยังต้องสำรองข้อมูลอยู่

## ย้ายข้อมูลระหว่างเครื่อง (Export / Import JSON)
1. ที่เครื่องต้นทาง ไปที่แท็บ "ตั้งค่า" แล้วกด **Export JSON** จะได้ไฟล์ชื่อ `money-backup-YYYY-MM-DD.json` ซึ่งมีครบทั้งรายการ หมวด และงบ
2. ส่งไฟล์นั้นไปยังอีกเครื่อง เช่น ทาง LINE อีเมล หรือ Google Drive
3. ที่เครื่องปลายทาง ไปที่แท็บ "ตั้งค่า" กด **Import JSON** แล้วเลือกไฟล์นั้น

**สำคัญ: Import จะแทนที่ข้อมูลทั้งหมดในเครื่องปลายทาง** โดยไม่รวมกับข้อมูลเดิม แอปจะถามยืนยันก่อนทุกครั้ง ส่วนไฟล์ที่ผิดรูปแบบ แอปจะแจ้ง error และไม่แตะข้อมูลเดิม

## ข้อควรระวังเรื่องข้อมูล
- ข้อมูลเก็บอยู่ในเบราว์เซอร์ของแต่ละเครื่องเท่านั้น (key `money-tracker-v1` ใน localStorage) แอปไม่ซิงค์ระหว่างเครื่องให้เอง
- ถ้าล้างข้อมูลเบราว์เซอร์ (ล้างคุกกี้/ข้อมูลเว็บไซต์) ข้อมูลในแอปจะหายด้วย
- Safari บน iOS อาจลบข้อมูลของเว็บที่ไม่ได้เปิดนาน
- **ควร Export JSON สำรองเก็บไว้เป็นระยะ** เช่น สัปดาห์ละครั้ง
- ถ้าเปิดแอปไว้หลายแท็บหรือหลายหน้าต่าง แอปจะไม่ให้เขียนทับข้อมูลของอีกแท็บ แต่จะโหลดข้อมูลล่าสุดมาแสดงแล้วขึ้นข้อความ "ข้อมูลถูกแก้จากแท็บหรือหน้าต่างอื่น โหลดข้อมูลล่าสุดแล้ว กรุณาทำรายการอีกครั้ง" ถ้าเห็นข้อความนี้ ให้ทำรายการเดิมซ้ำอีกครั้ง
- ถ้าข้อมูลใน localStorage เสีย แอปจะแจ้ง error และไม่บันทึกทับ ให้ Import ไฟล์สำรองเพื่อกู้ข้อมูล

## Export CSV (เปิดใน Excel)
กด **Export CSV** ในแท็บ "ตั้งค่า" จะได้ไฟล์ที่มีรายการทั้งหมด มีคอลัมน์ วันที่, ประเภท, หมวด, จำนวนเงิน, โน้ต ไฟล์ใส่ UTF-8 BOM ไว้แล้ว Excel จึงแสดงภาษาไทยได้ ส่วนโน้ตที่มีคอมม่า เครื่องหมายคำพูด หรือขึ้นบรรทัดใหม่ จะถูกครอบด้วยเครื่องหมายคำพูดให้ถูกต้อง และข้อความที่ขึ้นต้นด้วย `=` `+` `-` `@` จะมี `'` เติมไว้ข้างหน้า เพื่อไม่ให้ Excel มองเป็นสูตร

CSV ใช้สำหรับดูหรือวิเคราะห์ต่อเท่านั้น จะ import กลับเข้าแอปไม่ได้ ถ้าจะสำรองข้อมูลให้ใช้ JSON

## ข้อจำกัด / สิ่งที่ยังไม่ทำ
- ไม่มีระบบล็อกอิน และรองรับผู้ใช้คนเดียว
- ไม่มี server หรือฐานข้อมูลออนไลน์ และไม่ซิงค์อัตโนมัติ ย้ายข้อมูลได้ด้วยไฟล์เท่านั้น
- Import มีแบบแทนที่ทั้งหมดอย่างเดียว ยังรวมข้อมูล (merge) ไม่ได้
- Import จาก CSV ไม่ได้ (CSV ใช้ export อย่างเดียว)
- ใช้ได้สกุลเงินเดียว (บาท) และมีบัญชีหรือกระเป๋าเงินเดียว
- งบใช้ค่าเดียวกันทุกเดือน ไม่มีงบแยกรายเดือน และไม่ยกยอดงบที่เหลือไปเดือนถัดไป
- ไม่มีรายการเกิดซ้ำอัตโนมัติ ไม่เชื่อมธนาคาร และไม่สแกนสลิป
- ไม่ใช่แอป native ไม่ใช่ PWA และไม่มี service worker
- ยังไม่ได้ deploy ขึ้นโฮสต์
- ยังไม่ได้ทดสอบบนมือถือจริง ดูรายการที่ต้องลองและข้อสังเกตที่รู้แล้วได้ใน [CHECKLIST.md](CHECKLIST.md)
